# Contributing Guidelines

Thank you for your interest in the FSWM project!

This repository is maintained and owned solely by **emlbahagan**. Currently, this is a closed project, and direct pushes to the main branch are restricted to **emlbahagan** only.

## Security & Workflow Policy
- Direct push permissions are restricted exclusively to `@emlbahagan`.
- Contributions from other developers are subject to pull request reviews and authorization from the owner.

## Development Workflow
1. **Branching**: For any feature work, create a separate branch off `main` (e.g., `feat/feature-name`).
2. **Linting & Verification**: Run linting and formatting locally before submitting changes:
   ```cmd
   npm run lint
   npm run build
   npm run test
   ```
3. **Commit Messages**: Follow conventional commits naming guidelines.
